# VS Code

Open **`eZeGo.code-workspace`** (File → Open Workspace from File, or `code eZeGo.code-workspace`).
It is generated by `init` / `tools` / `./ez vscode` with the paths found on this machine, and
is git-ignored. The tracked `.vscode/` files contain no machine paths; they read the generated
values through `${config:ezego.*}`. Your own settings go in `.vscode/settings.json` (also ignored).

Install the recommended extensions when prompted: CMake Tools, clangd, CodeLLDB, and the Microsoft
C/C++ extension (only for its Windows debugger; its IntelliSense is disabled in favour of clangd).

## Everything without a terminal

| Want | Click |
|---|---|
| Switch mode | CMake Tools status bar → configure preset: `debug` / `profile` / `release` / `asan` / `tsan` |
| Build | status bar **Build**, or F7 |
| Run / debug | pick the target (`ezego`) → F5 → "Debug app (LLDB)" (Windows: "Debug app (Windows)") |
| Tests | Testing view (CTest via CMake Tools) |
| Profile | select the `profile` preset → F5 → "Run app + Tracy", or the task **ez: profile** |
| doctor / init / deps / tools / check | Terminal → Run Task → `ez: …` |

Every task runs the same canonical command as the terminal (`cmake -P scripts/<task>.cmake`), so
the two can never disagree.
